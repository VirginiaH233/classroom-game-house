# 课堂游戏屋 🎮

> 把点名抽签、随机分队、抢答竞赛、积分榜、计时器等 9 个课堂小工具，装进一个"像素掌机"。

打开一个网页就能带完整堂课：**单文件、离线可用、无需安装和联网**。

## 为什么做这个

在学校工作的一年里，最常听老师吐槽的不是备课，而是课堂上的"杂活"：随机点名怕被说偏心、分组分得手忙脚乱、游戏环节热热闹闹但加分算分全凭手速、下课铃一响还有队伍积分没算完……

课堂游戏屋把这些杂活接了过去，其中**「分队 + 积分」**是课堂上最常用、也是最省事的一环：一键随机分队或座位表手点，积分跟着班级走，下课一键「公布获胜队」大屏庆祝。

## 功能

| 模块 | 说明 |
|---|---|
| ▦ 座位表 | 座位网格，班级独立存储；支持批量导入名单、行列增减、删除本班 |
| 🎯 点名抽签 | 随机抽人（不重复），或转盘抽取，抽中大字动画 |
| 🚂 开火车 | 全班按座位顺序接龙回答，推进 / 对错两种模式 |
| 🔥 课前热身 | 击鼓传花、定时炸弹 |
| 👥 分队 | 按每组人数随机分队，或座位表手点分组；改人数队伍实时增减 |
| 📊 积分榜 | 各游戏加分的汇总，一键公布获胜队 |
| 🏆 抢答竞赛 | 出题抢答、对错记录、座位高亮 |
| ⏱ 计时器 | 课堂倒计时 |
| 🎲 随机决定 | 骰子 / 二选一 / 任务大转盘 |

其它：
- 像素掌机美术风格（让课堂更轻松活泼）
- 组件缩放 50%~150%，适配一体机 / 投影 / 笔记本，并记住上次倍率
- 课堂模式：隐藏导航，全屏纯净大屏

## 使用

1. 下载 `课堂游戏屋.html`（或 `index.html`），双击用浏览器打开；
2. 在「座位表」录入班级名单（可批量导入），数据保存在浏览器本地；
3. 上课直接用，无需联网。

> 建议用 Chrome / Edge 打开。数据存在本机浏览器，清除浏览器数据会一并清除。
